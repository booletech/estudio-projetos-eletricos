## Como usar

Ler o guia relevante e consultar a fonte indicada para a dúvida. Registrar
uma hipótese como hipótese e um exercício como planejado até haver evidência
de execução. Novas revisões devem ser numeradas; manter esta como histórico.
O catálogo também existe em formato estruturado: [fontes-001.json](fontes-001.json).

## Estado

Esta base reúne resumos próprios, links e instruções para consulta. Não houve
treinamento de pesos, instalação de agentes autônomos nem execução de novos
projetos nesta etapa. A leitura não garante domínio prático; os exercícios
propostos e a revisão humana permanecem pendentes. Não foi feita pesquisa
normativa completa, nem foram definidos critérios de dimensionamento elétrico.

Versões locais de referência: LibreCAD 2.2.1.5 e QElectroTech 0.100, git8590.
O manual LibreCAD `latest` declara ser de pré-lançamento; o ramo estável
consultado descreve 2.2.0. Algumas páginas QET ainda mencionam 0.7. Conferir
funções e menus na versão instalada antes de transformá-los em procedimentos.
