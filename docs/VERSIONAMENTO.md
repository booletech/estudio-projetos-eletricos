# Fluxo de preservação e atualização

1. Trabalhar na cópia local deste repositório. Não misturar os arquivos do
   estúdio de vídeo com os do estúdio elétrico.
2. Para importar CAD autorizado, copiar o original para uma saída numerada e
   registrar SHA-256. Não alterar o original.
3. Antes do envio, revisar arquivos e diferenças. A autorização permanente
   cobre `exemplos/` sintéticos, `agentes/`, `scripts/`, `docs/` e arquivos de
   configuração do repositório. Novos projetos identificáveis exigem autorização
   específica antes do upload, mesmo que o Git consiga adicioná-los.
4. Ignorar `.venv`, `tools`, `local`, segredos, instaladores e backups CAD.
5. Conferir o estado remoto e evitar conflitos. Usar commits comuns e envio
   sem força. Se houver conflito, preservar os dois lados e solicitar a decisão
   necessária. Não reescrever histórico.
6. Executar as verificações adequadas. Registrar falhas e limitações com clareza.
7. Enviar um commit descritivo somente se houver alteração real autorizada.
   Informar o resultado ou impedimento relevante; ficar em silêncio sem mudanças.

Não criar alterações artificiais para cumprir a frequência diária. O agendamento
vive no Codex; não há tarefas agendadas do Windows nem workflow pago configurado.
